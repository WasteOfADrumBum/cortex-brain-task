# Project logos for Ops

Each Ops card shows a live screenshot of the project's site, with its logo in the corner. A project with no site, or
a screenshot that can't be made, shows the logo full size instead.

To use your own logo, add it here named after the project, lower case with dashes:

| Project | File |
| --- | --- |
| Cortex | `cortex.png` |
| OneSmallUI | `onesmallui.png` |
| Portfolio | `portfolio.png` |
| One Small Studio | `one-small-studio.png` |
| One Small Photo | `one-small-photo.png` |
| ModsPack | `modspack.png` |
| Engineering Hub | `engineering-hub.png` |

Ops looks for the `.png` first and falls back to the `.svg` placeholder that is already here, so nothing else needs
changing. A wide image (about 16 by 10) fills the card best; a square logo is shown centred.
